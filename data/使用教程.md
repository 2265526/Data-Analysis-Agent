# 📊 Data Pipeline Agent 使用教程

> 数据分析智能体平台:输入自然语言需求(如"统计最近 7 天各品类销售额,对比上周变化"),自动产出含图表、明细、行动建议的分析报告。
> 支持多会话对话、人机协同审批、操作日志审计、用户权限管理、指标口径锁定、数据血缘溯源、MCP 预检。

---

## 一、组件一览(本机当前状态)

| 组件 | 作用 | 状态 | 说明 |
|---|---|---|---|
| PostgreSQL(`:5433`) | 业务数据 + 平台元数据(任务/会话/用户/审计/成本) | ✅ 运行中 | 建表由启动引导自动完成 |
| Redis(`:6379`) | 结果缓存 / 取消标志 / Celery broker | ✅ 运行中 | 系统服务 |
| Chroma(`:8000`) | 历史成功代码向量检索 | ✅ 运行中 | 不可用时自动降级 |
| Docker + 沙箱 `data-sandbox:v1` | Python 代码隔离执行 | ✅ 可用 | 无网络/资源限制/30s 超时 |
| LLM | DeepSeek(核心推理) + DashScope(低成本) | ✅ 已配 | `.env` 配置密钥 |
| postgres-mcp | PostgreSQL MCP Server(restricted 只读) | ✅ 已装 | `PG_MCP_ENABLED=0` 可关闭 |
| Celery worker | 异步任务队列 | ⚠️ 可选 | 不启动自动回退后台任务 |

## 二、日常启动

```bash
cd /home/cai/t_data/Data_Enginerting_Agent

# 终端 1:后端 API + 前端页面(同源托管 web/dist, :8001)
# 注意: 必须用 --reload-dir src 限定热重载范围, 否则 .venv 变化会触发无限重启
.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8001 --reload --reload-dir src

# 终端 2(可选):Celery worker(不启动自动回退到 FastAPI 后台任务)
.venv/bin/celery -A src.api.routes:celery_app worker --loglevel=info

# 终端 3(可选,前端开发模式):Vite dev server(:5173, /api 与 /static 代理到 8001)
cd web && npm install && npm run dev
```

浏览器打开 **http://localhost:8001**(生产模式,后端托管前端);开发改前端时访问 **http://localhost:5173**(热更新,修改后 `npm run build` 使后端托管新产物)。

## 三、使用流程

1. **登录**:输入 admin/密码(默认 `admin/admin`)。管理员进入管理端;普通用户/审批人进入数据分析页。
2. **会话管理**(左侧栏):
   - **新建会话**:点"＋ 新建会话",开始新一轮对话(新旧会话隔离,旧会话保留在列表)。
   - **会话操作**:每个会话右侧 **⋯** 按钮 → 置顶 / 重命名 / 删除(删除会话不影响任务历史)。
   - **切换会话**:点击列表项恢复该会话的历史消息与报告。
3. **发起分析**:在输入框输入业务问题,例如
   > 统计最近 7 天各品类销售额,对比上周变化

   支持三种输出偏好:
   - 默认:生成完整报告(执行摘要/正文/图表/明细/建议) + PDF + 看板
   - 显式要 PDF:在需求里说"生成 PDF 报告"
   - 只要答案:在需求里说"不用报告,给我答案就可以" → 简洁问答(一句话答案)
4. **实时进度**:任务卡片显示进度条与当前环节(拆解 → 写 SQL → 执行 → 生成报告)。
5. **人工审批**(触发时):敏感表查询/大结果集/显式审批流会挂起,卡片出现"批准/拒绝"表单 → 填意见 → 任务从断点继续。
6. **查看结果**:完成后任务卡片展示报告正文;可下载 PDF、查看交互式看板(品类点击下钻明细)。
7. **任务历史**:侧边栏"任务历史"查看全部已提交任务(关键词/状态筛选),已完成的报告可随时回看下载。

## 五、高级功能

| 功能 | 触发/说明 |
|---|---|
| **多会话** | 会话隔离/置顶/重命名/删除/切换;消息与报告持久化,刷新不丢失 |
| **简洁问答** | 需求含"只要答案/不用报告"等 → 一句话答案,不生成报告/看板/PDF |
| **指标口径锁定** | 平台指标目录(如近7天销售额=SUM(total_item_amount) 且订单已完成)注入 coder,跨任务口径一致;**管理员在「指标口径」页通过 选表→选列→选算法 定义(数据来源可多选跨库, 表清单自动合并),不用写代码,立即生效** |
| **数据血缘溯源** | 报告附录展示每步查询的来源表/行数/耗时;看板页点「数据溯源」可重跑任意一条 SQL 核验报告数字 |
| **数据源配置化** | 管理员在「数据源」页**按提示填写地址/库名/账号(分字段表单, 支持模板预填)**,测试连接后**勾选要分析的表**即可接入;连接信息加密存储 |
| **数据级权限** | 管理员在「数据权限」页配置 表/列/行级 访问控制:**列从数据库自动加载选择,模式用中文(可见/脱敏/禁止)**,行级过滤有业务示例;SQL 执行前强制 |
| **定时任务+通知** | 所有登录用户可在「定时任务」页配置**执行频率(每天/每周几/每月几号 + 时间, 不用懂 cron)**定期自动跑分析;**可多选数据源跨库执行(每个库各跑一次)**;结果**站内通知**默认只发给创建人,管理员可额外设置**推送人员范围** |
| **审计导出** | 操作日志支持按筛选条件导出 CSV 归档;**审计为 append-only,不提供清空接口** |
| **敏感表保护** | SQL 命中敏感列(phone/id_card/password 等)自动转人工审批 |
| **大结果集审批** | 执行结果行数超阈值 → 全量落盘精确统计(不压缩/不摘要), 挂起人工审批, 批准后报告/图表/看板基于全量 |
| **时间范围统一解析** | 支持**显式日期区间**(如"2026年8月5日到2026年8月11日"、"2026年8月7日"单日)与相对窗口(近7天/上周/近30天/上月/近1年), 系统统一锚定为绝对区间并贯穿 查询/趋势图/下钻/报告统计周期, 口径一致 |
| **趋势图窗口随查询** | 趋势图窗口=你的查询范围(如"近7天"→近7天按天; "8月5日到11日"→该区间按天), 不再固定近8周 |
| **看板下钻动态** | 下钻的**指标列与时间口径随查询动态**: 查"8月7日各品类销售额"→下钻显示 8月7日单列销售额; 查"各品类订单数量"→下钻显示订单数(不再写死近7天/上周/销售额) |
| **报告质量校验** | 报告生成后两道关卡: 规则校验(统计周期与 SQL 事实强制一致) + LLM 质量门禁(比对查询/报告/数据, 不一致自动重生成一次) |
| **MCP 复杂 SQL 预检** | 多表 JOIN/CTE/子查询/长 SQL 执行前 EXPLAIN 预检,错误自动回灌修复 |
| **自修复** | 执行失败自动重写(≤3 次),语法/逻辑错误分类处理 |
| **结果缓存** | 同需求+同结构复用历史成功 SQL,省一次 LLM 调用 |
| **进程内指标** | `/metrics` Prometheus 文本(任务/重试/耗时/Token,重启清零,执行任务后自动生成) |
| **看板下钻** | 报告看板中点击品类/指标查看明细,可返回 |

## 六、操作日志(管理员)

- 查看路径:管理端 → **操作日志**。
- **搜索**:输入关键字匹配 提交者 / 操作内容(任务) / 审批者 / 备注。
- **筛选**:点"筛选"弹出面板,可组合设置 提交时间区间 / 提交者 / 审批人 / 审批结果 / 执行结果;**不选默认全部**。
- **导出归档**:点"导出 CSV"按当前筛选条件导出全量审计(Excel 可直接打开);**审计日志为 append-only,系统不提供任何清空途径,导出归档是唯一外取方式(合规要求)**。
- **详情**:点"详情"查看单任务完整时间线(提交/规划/编码/执行/审批/报告)。

## 八、API 速查(curl)

```bash
# 登录
TOKEN=$(curl -s -X POST localhost:8001/api/v1/auth/login -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['access_token'])")
AUTH="Authorization: Bearer $TOKEN"

# 提交任务
curl -s -X POST localhost:8001/api/v1/tasks -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"query":"统计最近7天各品类销售额,对比上周变化"}'   # → {task_id}

# 查状态(含进度/报告)
curl -s localhost:8001/api/v1/tasks/{task_id}/status -H "$AUTH"

# 审批(awaiting_approval 时)
curl -s -X POST localhost:8001/api/v1/tasks/{task_id}/approve -H "$AUTH" -H 'Content-Type: application/json' \
  -d '{"approved":true,"approver":"admin","comment":"同意"}'

# 下载报告(PDF)
curl -s -OJ localhost:8001/api/v1/tasks/{task_id}/download -H "$AUTH"

# 会话:新建/列表/消息
curl -s -X POST localhost:8001/api/v1/chat/sessions -H "$AUTH"
curl -s localhost:8001/api/v1/chat/sessions -H "$AUTH"
curl -s localhost:8001/api/v1/chat/sessions/{session_id}/messages -H "$AUTH"

# 操作日志(搜索+筛选)
curl -s "localhost:8001/api/v1/admin/audit-logs?keyword=admin&approval_result=approved" -H "$AUTH"

# 监控指标
curl -s localhost:8001/metrics
```

## 十、常见问题

| 问题 | 解决 |
|---|---|
| 后端热重载后无限重启 | 启动时务必加 `--reload-dir src`(默认会监视 .venv) |
| 进程内指标全部"暂无数据" | 正常现象:指标是进程内存态,重启清零;执行任一分析任务后自动生成 |
| 会话内任务一直"提交中"但任务历史已完成 | 刷新页面(旧版前端 bug 已修复;消息卡片与轮询共用同一对象) |
| 报告链接 404 | 确认 `static/reports` 目录存在且后端可写 |
| Chroma 不可用 | 服务降级不影响主流程(检索自动跳过) |
| 沙箱执行失败 | 确认 Docker 可用、镜像 `data-sandbox:v1` 存在(`docker images`) |
| 想关闭 MCP | 后端启动前设置 `PG_MCP_ENABLED=0` |
| 审批人无法审批 | 确认该用户角色含 `approver`(管理员可调整权限) |
